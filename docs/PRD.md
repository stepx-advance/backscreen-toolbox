## 1. 产品目标与范围

让用户在不打开主屏的情况下，看懂充电进度、掌握计时、留意新消息，并通过音乐、角色动画和声音频谱使用背屏。信息应清楚，动画应耐看，操作应简短。

- **实用**：电量、剩余时间、验证码等关键信息准确、完整、易读。
- **点阵品质**：在原生网格上设计构图、字形、留白和亮度层次；视觉品质是所有功能的基础要求。
- **可控**：按功能启用和授权，明确当前任务、预览与停止入口，临时提示结束后回到仍有效的任务。
- **本地运行**：无需 Root 或 Shizuku；无网络权限，不引入广告、分析或远程采集服务。

当前范围是六项背屏功能、统一首页、设置引导及运行恢复。最低安装版本为 Android 14，不代表其他机型或固件已兼容。不包含充电硬件控制、六麦克风声源定位、语音识别、音频保存、云同步或对系统高优先级背屏场景的强制覆盖。

## 2. 核心使用流程

1. **首次使用**：安装 → 阅读一屏设置清单 → 按条目打开图解和对应系统设置 → 启用工具箱。可选功能不阻塞普通充电显示。
2. **选择功能**：查看顶部当前背屏预览 → 点击标签或左右滑动 → 在下方完成当前功能的设置或启动操作。浏览功能页不改变实际背屏任务。
3. **临时提示**：消息或计时完成到来 → 按优先级展示 → 提示到期后恢复仍有效的任务，不重置原计时。
4. **主动停止**：从当前功能停止播放或聆听；关闭总开关则停止工具箱任务、取消计时提醒与恢复任务、释放资源并交还背屏。

## 3. 首页与设置交互

| 编号 | 需求 |
| --- | --- |
| UI-01 | 顶部展示当前实际背屏任务和画面，清楚区分真实状态、效果预览、关闭及连接状态。 |
| UI-02 | 下方提供六项横向功能标签；点击与左右滑动保持选中项一致，返回页面保留所选功能。 |
| UI-03 | 设置随功能变化。移除重复标题、重复状态、重复入口和自我解释的长文案；优先让常用操作在一屏可见，空间不足时仅设置区滚动。 |
| UI-04 | 共用顶部预览入口，12 秒后或手动结束时恢复有效任务。预览不创建计时提醒、不替换真实计时；“听见”预览使用明确标识的合成输入，不开启麦克风。 |
| UI-05 | 计时预设用两行卡片呈现；计时期间集中显示暂停／继续、结束和改时长。自定义分秒输入需校验并保留错误提示。 |
| UI-06 | 总开关、通用旋转、权限和后台设置集中在顶部“设置”；必要权限缺失时，在相关功能就地提供系统设置入口。 |

## 4. 功能需求

| 编号 | 功能 | 触发与主要设置 | 背屏表现与结束行为 |
| --- | --- | --- | --- |
| F-01 | 充电显示 | 工具箱及充电显示开启、设备接电；旁路识别独立可选 | 显示真实电量及充电、满电、旁路、等待或暂停状态；数字稳定。按系统真实状态判定充满，不将旁路或暂停等同于满电。无其他任务且拔电时交还系统。 |
| F-02 | 背屏计时器 | 番茄钟、做饭、泡茶／倒茶、小憩、运动；支持自定义分秒、暂停、继续、结束及修改时长 | 大数字为主要信息。保存截止时间用于恢复，覆盖安装不重新开始计时；到点显示完成画面约 20 秒，短暂震动，并按通知权限显示提醒。 |
| F-03 | 新消息提示 | 用户主动启用消息监听；可选择消息来源应用，验证码展示可单独关闭 | 普通消息使用克制动效，不展示正文，约 10 秒后清除。仅对最新一条可识别验证码展示来源和完整 4–8 位数字／字母，保留大小写，最多 25 秒；新消息替换旧提示，撤回或到期清除。系统遮挡验证码时退回普通提示。 |
| F-04 | 音乐伴随 | 用户主动启用并授权；读取活动媒体会话 | 仅播放期间显示唱片动效与歌名，长标题可滚动；暂停后回到有效任务。该动效不表示真实录音频谱，不使用麦克风。 |
| F-05 | 奶蛙大笑 | 用户手动开始，可选一分钟或持续播放 | 以重新绘制的点阵角色和有停顿的笑声节奏呈现；到期或手动停止后退出。角色来源与权利范围见 [NOTICE](../NOTICE.md)。 |
| F-06 | 听见 | 用户主动开始并允许麦克风；提供三档灵敏度与明确停止入口 | 使用 D「频谱山形」：17×23 竖屏，15 个约 80 Hz–12 kHz 频段从左低频到右高频，亮色山顶与较暗块面分层。真实输入驱动，不逐帧自动拉满，强声保留余量，安静时平静回落。停止后释放麦克风；开机、更新及进程重建不自动开始聆听。 |

“听见”只以竖屏为设计和验收范围，不加入应用内横屏排版或旋转过渡；系统背屏旋转仍由固件控制。当前公开接口未核实六路独立麦克风，使用已确认可用的输入，不据此推断物理麦克风数量或声源方向；频谱也不作为校准声压测量。

### 场景优先级与切换

正常任务按以下顺序选择可显示场景：

**新消息 → 计时完成 → 计时（含暂停）→ 听见 → 手动奶蛙 → 正在播放的音乐 → 充电 → 交还系统。**

效果预览是用户主动触发的临时展示，与正常任务选择分开处理；预览结束时重新选择仍有效的场景。高优先级提示只暂时替代背屏画面，不等同于取消较低优先级任务；例如计时被消息覆盖时仍按原截止时间结束，已主动开始的聆听需要用户停止才释放麦克风。主界面和系统使用标识须让用户知晓采集仍在进行。

系统来电、相机、人脸识别或 Amoo 等场景的优先级由固件决定，可能暂时覆盖工具箱；系统交还后恢复有效场景，不通过关闭系统能力或修改保护策略争用背屏。

## 5. 点阵与动效要求

- 在原生 17×23 网格上逐点设计；支持横屏的功能按当前固件中央 17×17 有效区域重排，确保轮廓、数字及百分号完整。“听见”遵循上述竖屏例外。
- 一幅画面突出一个主体，使用有限亮度层次，留白输出为暗点；避免无意义边框、持续全屏闪烁和随机装饰。
- 旋转过渡覆盖图标与数字整组，最终布局和阅读方向一致；允许关闭过渡。平放保持最后有效方向，方向输入中断时安全回退并尝试恢复。
- 数字和验证码需有稳定阅读时间；长代码保持完整，区分大小写及 `0/O`、`1/I/l`，不以动效遮盖识别问题。
- 循环应有变化、停顿和自然衔接。声音驱动画面需反映真实强弱与频段差别，不用预设波动伪装输入。
- 视觉修改先从生产绘图代码导出关键帧和完整循环；方向被否定时先比较动态候选，再集成并做实物检查。详见 [点阵视觉设计基线](VISUAL_DESIGN.md)。

## 6. 首次设置、权限与隐私

| 项目 | 应用自动处理的部分 | 用户需要完成的部分 |
| --- | --- | --- |
| 基础显示 | 读取电量与接电状态，选择场景，绘图并提交背屏 | 启用工具箱；在系统开启背屏，按需要选择持续显示与自动旋转 |
| 后台运行 | 按已开启设置尝试前台运行、更新恢复及首次解锁后恢复 | 同意电池优化豁免；核对原厂“允许自启动”和“允许后台运行” |
| 引导清单 | 提供图解、关键位置红框和对应系统页面入口 | 在真实系统页面开启开关；原厂后台开关不能读取时，由用户核对后记录完成 |
| 旁路识别 | 仅过滤原厂电池状态通知 | 可选授权“旁路识别（系统电池通知）” |
| 消息与音乐 | 按功能开关处理新通知或当前媒体会话 | 主动开启所需功能，并独立授权“消息与音乐背屏（可选）” |
| 计时 | 按截止时间调度、保存状态、到点提醒 | 首次开始前按需允许“闹钟和提醒” |
| 听见 | 开始后在内存计算频谱，停止时释放输入 | 主动开始并授予麦克风权限；系统保留麦克风使用标识 |
| 通知栏显示 | 前台服务向系统提供运行通知 | 通知抽屉是否显示可选；拒绝后系统“活动应用”仍可能显示运行标识 |

红框属于应用内静态设置图解，不覆盖真实系统界面。首次设置和覆盖升级不能擅自重新开启用户已关闭的功能。公开版沿用包名和签名进行覆盖升级；内部旧包名的设置与授权需独立处理。

普通消息正文、验证码、媒体元数据和声音仅用于当前本地处理，不写入文件或日志；验证码最长按展示时限留在内存。PCM 和频谱工作区处理后清空，不保存音频、不识别语音、不上传。验证码可能在锁屏背屏可见，启用交互需明确提示。权限拒绝、撤销或系统将麦克风静音时，应显示真实状态，不用合成效果冒充运行。完整约束见 [权限与隐私](PRIVACY.md) 和 [设置说明](SETUP.md)。

## 7. 可靠性与运行边界

用户关闭总开关后应明确停用，系统强停不能被当作必然可自动恢复的状态。前台服务、开机／更新恢复及低频充电恢复均受 Android 和原厂后台策略约束；失败时提供手动打开应用和检查后台设置的路径。

方向与动画仅在需要更新时保持运行；省电、严重温升或不可见姿态下按策略让出资源。主动聆听有独立采集保持条件和停止入口。背屏朝下、双击熄灭、显示时限及系统电源策略可能使硬件不亮，画面提交成功不能单独作为实物可见的证据。

## 8. 验收要求与当前证据

| 编号 | 验收场景 | 通过条件 |
| --- | --- | --- |
| AC-01 | 首次安装、拒绝可选权限、关闭后重新打开 | 必要设置路径可达；可选权限不阻塞基础功能；不循环引导，不越过用户关闭决定。 |
| AC-02 | 首页切换、滑动、预览与返回 | 选中页一致，浏览不启停真实任务；12 秒预览及手动结束能恢复任务，真实计时截止时间不变。 |
| AC-03 | 充电、满电、暂停、旁路及方向切换 | 数值与真实状态一致，横竖排版完整，整组过渡自然；亮屏、锁屏及快速反向切换分别验证。 |
| AC-04 | 计时暂停／继续、覆盖升级、熄屏到点 | 不重置截止时间，不创建重复提醒；按状态完成提示并恢复有效场景。 |
| AC-05 | 真实新消息、验证码、撤回、媒体播放／暂停 | 来源过滤、最新一条、代码完整及超时清除正确；不读取或重放历史消息；不保存敏感内容。 |
| AC-06 | 听见的静音、轻声、说话、拍手及停止 | 山形有频段细节、强弱区别与上限余量；无虚构输入；结束、权限异常和进程中断能释放麦克风，重建不自动录音。 |
| AC-07 | 场景抢占、系统覆盖和运行恢复 | 临时提示后返回有效任务；总开关关闭可交还系统；系统覆盖结束、熄屏、进程重建及首次解锁恢复分别留存结果。 |
| AC-08 | 视觉与发布 | 生产帧尺寸、边界、亮度和循环检查通过，再核对真实背屏观感；公开 APK、源码、版本、签名和校验文件对应。 |
