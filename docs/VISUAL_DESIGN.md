# 点阵视觉设计基线

点阵画面的清晰度、构图和动效品质是 STEPX 背屏工具箱的基础要求。每个新功能和后续修改都需要按此检查；能显示出数据只是第一步。

## 在原生网格上设计

- 先在 17×23 的实际网格画静态关键帧，再做动画，不把高分辨率插画缩成一团。
- 需要横竖一致的图案，使用中央 17×17 安全区。主轮廓与数字都要检查三个阅读方向、三个系统固定方向锚点的最终投影。
- 一幅画面只突出一个主体。围绕主体留空，间隔至少一个暗点的相邻细线更容易辨认；没有信息作用的边框不占用网格。
- 图标先看轮廓是否可识别，数字先看是否完整。不要靠长说明、闪烁或随机装饰补救构图。

## 亮度有层次

- 用暗点、辅助亮度和主体亮度区分层次。避免每个像素都处在最高亮度，避免相邻形状连成亮块。
- 细线按整数坐标落点，不用模糊滤镜制造轮廓。运动边缘可以使用少数亮度阶梯，减少整行突然出现的跳变。
- 预览显示未点亮的网格仅用于辨认分辨率；实际输出中的留白必须是 0，不能加入装饰底噪。

## 动效应有节奏和含义

- 先做好静帧，再安排起势、变化、停顿与回归。持续动画要检查循环接缝，阅读中的数字与验证码保留稳定停顿。
- 优先移动少量关键点或高光，避免整幅图持续同频闪烁。亮度、形状、位置不同时无目的地变化。
- 输入驱动的动画真实跟随输入。静音归于平静，不用随机波动伪装实时声音；音乐伴随等合成动效与真实采集明确区分。
- 采样、显示与系统方向切换分别处理。动画不能拖慢输入，也不能用过渡掩盖错误的最终朝向。

## “听见”的当前实现：D 频谱山形

用户已从六种候选中选定 D 作为集成方向。原先的七条音量柱、峰值 / RMS 双层轮廓未获视觉认可；它们的运行证据不能作为当前频谱的实物验收。探索记录保留在 [绘图对比](../design/hear/README.md)。

- 使用原生 17×23 竖屏网格，不作应用内旋转、横屏重排或过渡。山形占 x=1…15、y=4…21，外围和顶部保留空间；系统背屏旋转仍由固件控制，竖屏完整显示需系统处于竖向。
- 15 列表示约 80 Hz–12 kHz 的对数频段，从左低频到右高频。高度由每段频率能量计算，明亮山顶（232）与较暗块面（80–144）构成一个主体；安静时回到低亮基线。
- 按约 25 ms 输入处理：去直流、选择 AC 能量最强的输入声道、Hann 窗、2,048 点零填充 FFT、按窗能量校正后积分频段功率。正常 48 kHz 输入使用 1,200 样本；实际采样率用于计算频段位置。零填充不提高真实频率分辨率。
- 三档灵敏度使用固定显示增益（9、18、36），归一化映射为 `频段 RMS × 增益 / (1 + 频段 RMS × 增益)`。不按每帧最大值拉满，强声也保留显示余量。约 25 ms 更新，快速响应与短时回落稳定山顶；安静后不生成虚构波动。
- PCM 与 FFT 工作区处理后清空，仅保留 15 个显示值。原生绘图函数与选定 D 候选共用；预览里的合成声音使用相同频段算法和绘图规则，不启用麦克风。
- 这是频谱，不是时域波形或声源定位，也不是校准声压计；系统 MIC 路径可能已经处理输入。真实声音、锁屏可见与审美认可分别验证。

## 每次视觉交付的检查

1. 从生产绘图代码导出关键帧与完整循环，查看实际网格和放大点阵，不用设计稿替代实现。
2. 比较静音、弱输入、正常输入和强输入；检查留白、亮度、裁切、最大值余量与循环接缝。
3. 在真实背屏确认亮度和观感。离屏好看、画面提交成功、实物可见以及用户认可分别记录。
4. 涉及方向、状态恢复或输入时，再检查真实状态切换。尚未验证的项目明确保留。

“听见”的可复现审图：先运行 `python3 tools/test.py`，再用装有 Pillow 的 Python 运行 `tools/hear_preview.py`，生成 `build/hear-preview/` 下的循环 GIF、静帧与关键帧表；所有输入均为合成数据。

## 研究参考

- [Adafruit：矩阵上的像素画](https://learn.adafruit.com/pixel-art-matrix-display/code-the-pixel-art-display)：按目标分辨率准备图案，保持清晰边缘，避免过度抗锯齿。
- [Adafruit：Pixel Art Fundamentals](https://learn.adafruit.com/makecode-arcade-pixel-art-sprites/pixel-art-fundamentals)：在有限画布与有限色阶中逐点决定形状。
- [Adafruit：Sprite Sheet Animation](https://learn.adafruit.com/pixel-art-matrix-display/sprite-sheet-animation)：先建立像素图案，再用少量有目的的帧与时序表达运动。
- [Audacity：Waveform / RMS](https://manual.audacityteam.org/man/audacity_waveform.html#RMS_display)：将时间片峰值与同片 RMS 以不同亮度层次表达。
- [BBC：audiowaveform](https://github.com/bbc/audiowaveform)：将一组输入样本归约为最小值与最大值，避免只取均值丢掉短促峰值。本项目没有使用它的实现或依赖。

以上是方法参考。本项目的安全区域、细线构图、亮度分层和增益参数是结合 STEPX 背屏与实测反馈作出的设计选择，没有复制参考作品的图案、代码或素材。本次先应用于“听见”；其他场景的既有画面仍需逐项验收，不能据此宣称全部已完成视觉升级。
