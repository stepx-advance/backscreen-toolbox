# 权限与隐私

适用于 STEPX 背屏工具箱 1.0.0，2026-10-18。

应用在手机本地处理数据，无网络权限，不上传数据，不包含广告、分析或远程崩溃收集 SDK。偏好保存在应用私有目录，卸载时由 Android 清除；不启用系统应用备份。

## 使用的数据

- 标准电池状态、真实电量和接电状态：用于选择点阵画面。
- 加速度、设备方向和背屏朝向：用于横竖屏排版、锁屏更新和传感器断流恢复。
- 本地设置：自动显示、旋转过渡、设置完成记录和最后方向。
- 本地运行诊断：状态变化、方向与采样情况、接口错误和恢复来源。系统日志/服务诊断可能包含电量、时间和进程信息，提交反馈前应检查并删去个人内容。

## 可选通知使用权

Android 的授权页面提供的是通知读取能力。本应用的实现只接受包名 `com.stepos.battery`、通知 ID `2001`、通道 `ChargeBypass`；在读取标题和正文前拒绝其他来源，再按系统电池组件的本地化文本判断旁路是否生效。

应用不保存、转发或上传通知正文，不处理聊天通知。你可以拒绝或随时撤销授权；此时仍可使用普通充电显示，但无法可靠识别旁路。固件改变通知格式或不发布通知时，旁路识别也可能失效。

## 声明的权限

| 权限/能力 | 用途 |
| --- | --- |
| 前台服务及 specialUse 类型 | 按用户开关持续更新点阵背屏 |
| 开机完成广播 | 首次解锁后尝试恢复已开启的显示 |
| 电池优化豁免请求 | 打开系统确认，减少后台中断 |
| 发送通知（可选） | 运行状态及恢复提醒 |
| 通知监听服务（需用户单独授权） | 识别原厂旁路状态 |
| 查询系统电池组件 | 读取本地化旁路状态资源 |
| 查询内部旧版 | 首次启用时提醒先关闭旧版，避免争用背屏 |
| CPU 唤醒锁 | 充电、熄屏且背屏朝上或竖直可见时，维持方向采样与动画更新 |

CPU 唤醒锁不点亮主屏，仅在已开启显示、实际接电、背屏朝上或竖直可见且动画或自动旋转需要更新时使用。亮屏、背屏朝下、拔电、关闭显示、系统省电或严重温升时释放；每次获取有超时并按条件续期。它属于普通权限，无需用户额外批准。实现参见 [Android 官方说明](https://developer.android.com/develop/background-work/background-tasks/awake/wakelock)。

不申请网络、存储、相机、麦克风、位置、悬浮窗或精确闹钟权限。不读写受保护的充电硬件节点。

问题请通过 [项目 Issues](https://github.com/stepx-advance/backscreen-toolbox/issues) 反馈，避免公开个人通知和原始设备转储。
