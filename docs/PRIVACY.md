# 权限与隐私

适用于 STEPX 背屏工具箱 1.1.0，2026-10-19。

应用在手机本地处理数据，无网络权限，不上传数据，不包含广告、分析或远程崩溃收集 SDK。偏好保存在应用私有目录，卸载时由 Android 清除；不启用系统应用备份。

## 使用的数据

- 标准电池状态、真实电量和接电状态：用于选择点阵画面。
- 加速度、设备方向和背屏朝向：用于横竖屏排版、锁屏更新和传感器断流恢复。
- 本地设置：自动显示、旋转过渡、设置完成记录和最后方向。
- 本地运行诊断：状态变化、方向与采样情况、接口错误和恢复来源。系统日志/服务诊断可能包含电量、时间和进程信息，提交反馈前应检查并删去个人内容。

## 两项独立的通知使用权

- **旁路识别（系统电池通知）**：保留原来的范围，仅接受 `com.stepos.battery`、ID `2001`、通道 `ChargeBypass`。授权它不会自动启用新消息或音乐读取。
- **消息与音乐背屏（可选）**：需在功能中主动开启，并单独允许通知使用权。消息默认按消息/邮件类别识别，也可指定应用；只处理新到达的通知，不在重新连接时展示历史通知。普通消息只提示有消息，不显示正文。验证码识别使用最新一条消息的正文，优先取 `MessagingStyle` 的最后一条；来源与验证码仅保存在内存，最多显示 25 秒，撤回、关闭或新消息到来时清除，不写入偏好、日志或诊断。关闭验证码后不提取验证码。Android 15 及以上可能遮住验证码，应用不绕过系统限制。

音乐读取当前活动媒体会话的播放状态、歌名和歌手。只在播放时显示，暂停后交还前一场景；不使用麦克风，不录音，律动是绘制的动效。媒体元数据不写入本地文件或日志。

两项权限均可撤销。拒绝消息与音乐权限时，充电、计时、奶蛙和内置效果预览仍可使用。

## 计时与动画

只保存预设、时长、运行/暂停状态以及到期时间，用于进程重建和开机后恢复计时。计时开始前请求系统“闹钟和提醒”，准时唤醒只用于用户主动开始的计时；结束时短暂震动并按通知权限显示提醒。关闭工具箱或结束计时会取消闹钟。

奶蛙大笑为程序绘制的点阵动画，可播放一分钟或手动持续播放，不采集数据。

## 听见

仅在用户点击“开始聆听”并授予麦克风权限后采集手机内置麦克风。约 25 ms 的 PCM 短缓冲仅在内存中进行窗函数与频谱计算，原始样本和 FFT 工作区在处理后清空；只保留 15 个经过短时稳定的频段显示值。不保留 PCM 历史、不保存音频、不识别语音、不上传，也不输出原始样本或实时频谱数据到日志、诊断或预览导出。只有灵敏度设置会保存。停止聆听、关闭工具箱或进程退出会释放麦克风；开机、更新和 sticky 服务重建均不会自动开始聆听。

聆听期间使用 microphone 前台服务类型，系统显示麦克风使用标识；运行通知提供“停止聆听”。缺少权限、输入中断或系统将采集静音时显示相应状态，不以合成声音冒充实际输入。检测只读取系统麦克风清单、输入格式和活动通道映射，不把六声道格式当作六个独立物理麦克风的证明。合成效果预览不申请或打开麦克风。

## 声明的权限

| 权限/能力 | 用途 |
| --- | --- |
| 前台服务及 specialUse 类型 | 按用户开关持续更新点阵背屏 |
| 麦克风及 microphone 前台服务类型（按需授权） | 用户主动开始“听见”后的实时频谱 |
| 开机完成广播 | 首次解锁后尝试恢复已开启的显示 |
| 电池优化豁免请求 | 打开系统确认，减少后台中断 |
| 发送通知（可选） | 运行状态及恢复提醒 |
| 两个通知监听服务（需分别授权） | 电池旁路；可选的新消息与媒体会话 |
| 闹钟和提醒（按需授权） | 用户启动的倒计时准时结束 |
| 震动 | 计时完成的短提示 |
| 查询可启动的应用 | 选择消息来源应用 |
| 查询系统电池组件 | 读取本地化旁路状态资源 |
| 查询内部旧版 | 首次启用时提醒先关闭旧版，避免争用背屏 |
| CPU 唤醒锁 | 可见背屏的方向/动画更新；用户主动聆听期间维持实时采集 |

CPU 唤醒锁不点亮主屏。背屏方向/动画锁仅在已开启显示、有活动任务、背屏朝上或竖直可见且动画或自动旋转需要更新时使用，亮屏、背屏朝下、任务结束、关闭显示、系统省电或严重温升时释放。“听见”另外在用户主动聆听期间保持采集锁，以免锁屏后实时处理暂停；每次最多持有 60 秒，采集仍在运行时续期，停止、连接超时或进程退出时释放。唤醒锁属于普通权限，无需用户额外批准。实现参见 [Android 官方说明](https://developer.android.com/develop/background-work/background-tasks/awake/wakelock)。

不申请网络、存储、相机、位置、悬浮窗权限。不读写受保护的充电硬件节点。

问题请通过 [项目 Issues](https://github.com/stepx-advance/backscreen-toolbox/issues) 反馈，避免公开个人通知和原始设备转储。
