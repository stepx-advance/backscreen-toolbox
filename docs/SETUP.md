# 安装与设置

## 从旧版迁移

公开版使用 `com.stepxadvance.backscreentoolbox`。即使签名证书相同，Android 仍将其视为独立应用；旧版的偏好、通知使用权、电池优化和原厂后台设置不会迁移。

先在旧版“背屏充电”关闭自动显示，再安装并开启“STEPX 背屏工具箱”。首次启用发现旧版时会提醒确认。应用不擅自卸载、强停或更改其他应用的授权。

## 五项清单

- **系统背屏**：打开系统“背屏显示”；需要持续显示时选择“始终显示”。应用仅检查背屏开关，不改亮度、文本和显示模式。
- **后台运行**：允许电池优化豁免。系统必须向用户确认，应用不能自行批准。
- **开机与后台恢复**：进入本应用信息的“耗电和后台”，选择手动管理，开启“允许自启动”和“允许后台运行”。无需开启“允许关联启动”。这组原厂开关无法由应用读取；勾选两项后保存的只是你的确认记录。
- **旁路识别**：可选。打开通知使用权，只处理系统电池组件的旁路状态通知。不开启也能显示普通充电、满电和暂停状态。
- **通知栏显示**：可选。Android 13 及以上可以拒绝通知权限，前台服务仍可运行，但系统活动应用标识仍会出现，恢复提醒也不能送达。参见 [Android 官方说明](https://developer.android.com/develop/ui/compose/notifications/notification-permission)。

条目先打开本机系统设置示意，再用“前往设置”打开真正的系统页面。红框属于应用内静态示意图，不会覆盖系统界面；不同固件的文字和位置可能变化。

电量读取、动画、方向监听、充电期恢复任务，以及开启后的更新/开机解锁恢复由应用处理。完成引导不会重新开启已经手动关闭的显示开关。

## 锁屏后背屏不亮

请先让背屏朝上、无遮挡，再核对系统背屏显示模式。即使应用仍在运行且画面提交成功，原厂系统也可能因背屏朝下、双击暂时熄灭、睡眠、省电、温度或显示时限关闭背屏。锁屏与主屏熄灭本身不能用来判断应用进程是否被清理。

本应用遵循这些系统策略，不通过持续点亮主屏或修改系统保护来维持背屏。反馈此问题时，请说明主屏是否熄灭、背屏朝向、供电方式和等待时间；不要只报告“进程仍在”。

## 停用与卸载

先关闭“自动显示充电状态”，确认原背屏恢复，再卸载。通知权限、通知使用权和后台设置均可在系统中撤销。系统“强行停止”或停止活动应用后可能需要手动打开应用恢复，不承诺从所有系统停止方式自动恢复。
