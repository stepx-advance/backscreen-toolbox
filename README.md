# STEPX 背屏工具箱 · Backscreen Toolbox

[STEPX Advance](https://github.com/stepx-advance) 系列的原生 Android 背屏工具。为 STEPX PZ261A 提供充电显示、计时器、新消息提示、音乐伴随、奶蛙大笑，以及实时声音频谱“听见”。

无需 Root 或 Shizuku。离线运行，无网络权限。非官方项目。

![充电、满电与旁路的横竖屏效果示意](docs/images/design-preview.png)

## 下载与安装

从 [1.1.0 正式版](https://github.com/stepx-advance/backscreen-toolbox/releases/tag/v1.1.0) 下载 `backscreen-toolbox-1.1.0.apk`，使用同页 `SHA256SUMS` 核对文件。

1. 在 PZ261A 上安装 APK，允许系统安装确认。
2. 打开“STEPX 背屏工具箱”，按一屏设置清单完成后台设置；每个条目都有红框图解和系统设置入口。
3. 开启充电背屏。旁路识别和通知栏显示均可跳过。

**从公开版 1.0.0 升级：** 直接覆盖安装，包名与签名保持一致，可保留设置。新增权限按所用功能单独开启；升级不会自动开启麦克风或消息读取。

**从内部版“背屏充电”迁移：** 先关闭旧版的“自动显示充电状态”，再开启新版，避免争用背屏。新版包名是 `com.stepxadvance.backscreentoolbox`，与旧版 `local.stepx.backcharge` 独立安装；保留原签名，但设置及授权不能自动迁移，需要重新完成。确认新版可用后可自行卸载旧版。

## 工具箱

1.1.0 新增五项玩法，并重新整理首页与点阵动画。

点阵画面的清晰度、留白、亮度层次与克制动效是所有功能的基础要求；新增或修改画面按 [点阵视觉设计基线](docs/VISUAL_DESIGN.md) 导出、审看并做实物检查。“听见”采用选定的竖屏频谱山形，以亮色山顶和较暗块面突出真实频段变化。

首页采用实时背屏预览、横向功能标签与当前功能设置。点击标签或左右滑动浏览，设置区仅保留当前功能的成组控件；浏览不会切换实际背屏任务。所有功能共用顶部“预览”入口，12 秒后恢复，也可以手动结束；计时预览不会创建提醒或替换正在运行的计时。计时预设为两行卡片，运行时只保留暂停、结束与改时长。总开关、旋转、通知权限与后台引导收进顶部“设置”；工具箱关闭时可以从预览卡直接启用。

- **计时器**：番茄钟、做饭、泡茶 / 倒茶、小憩、运动；自定义分钟与秒，暂停、继续、取消；用准时闹钟完成熄屏提醒，保存截止时间用于恢复。
- **新消息**：默认只显示克制的消息动效。最新一条包含可识别的验证码时，展示来源与完整的 4–8 位数字/字母，保留大小写；最多 25 秒后清除。Android 15+ 遮住验证码时退回普通提示。
- **音乐伴随**：读取活动媒体会话，仅播放时显示唱片微动和歌名滚动，暂停后返回原场景。动效不是录音频谱。
- **奶蛙大笑**：根据捧腹大笑参考重新绘制的点阵短帧，可播放一分钟或持续播放。
- **听见**：主动开始后将手机麦克风的声音变为竖屏频谱山形，使用 17×23 网格。15 个对数频段从左侧低频排到右侧高频，覆盖约 80 Hz–12 kHz；按 25 ms 输入计算频段能量，三档固定显示增益与软限幅保留强弱差别，不逐帧自动拉满。不做横屏排版或应用旋转；系统背屏自动旋转仍由固件控制。只在内存处理，不保存、上传声音。检测六声道实际映射，未核实为独立六路时回退到可用单／双声道，不标注未经核实的声源方位。顶部预览为合成示例，不启用麦克风。

![听见：生产绘图代码导出的合成频谱示例，非实拍](docs/images/hear-spectrum.gif)

![计时、消息、音乐与奶蛙：含虚构文字的绘图示例，非实拍](docs/images/toolbox-scenes.png)

新消息 → 计时完成 → 计时 → 听见 → 手动奶蛙 → 正在播放的音乐 → 充电，按此顺序选取应用场景；系统来电、相机与 Amoo 的优先级仍由固件决定。短提示结束会返回仍在运行的前一场景。消息优先，避免验证码被完成画面占用阅读时间；计时到点仍会震动，并按通知权限显示提醒。

消息与音乐需要独立的“消息与音乐背屏（可选）”通知使用权，不沿用电池旁路授权。首次开始计时会按需检查“闹钟和提醒”。详见 [权限与隐私](docs/PRIVACY.md)。

## 充电显示

| 状态 | 背屏显示 |
| --- | --- |
| 正在充电 | 电池、闪电和上行能量，电量数字保持稳定 |
| 系统确认充满 | 对勾和短暂星点，随后静止显示真实电量 |
| 旁路生效 | 能量绕过电池，保留真实电量 |
| 等待旁路生效 | 按当前充电状态显示，并附等待标记 |
| 接电但暂停充电 | 暂停符号与电量 |
| 拔掉充电器 | 交还系统原来的背屏内容 |

竖屏按 17×23 排版；横屏针对当前固件的中央 17×17 有效区域重排。旋转时图标与电量整组过渡，可单独关闭。主屏熄灭后继续跟随方向，并补偿系统冻结的背屏方向；如果系统停在横屏，转回竖屏时采用紧凑排版以保留完整电量。方向数据暂时中断时采用紧凑布局并尝试恢复。平放时保持最后方向，关闭系统背屏自动旋转后固定竖屏。

主屏提供实时状态、动画预览和 12 秒实物预览。关闭自动显示会停止服务、取消恢复任务并交还背屏。旁路识别只读取原厂状态信号，**不控制充电硬件**。

## 首次设置

| 清单 | 操作 |
| --- | --- |
| 系统背屏 | 开启“背屏显示”，需要持续显示时选择“始终显示” |
| 后台运行 | 接受系统电池优化确认 |
| 开机与后台恢复 | 应用信息 → 耗电和后台 → 手动管理，开启“允许自启动”和“允许后台运行” |
| 旁路识别（可选） | 允许通知使用权，仅读取系统电池状态通知 |
| 通知栏显示（可选） | 按需开启；拒绝后普通充电显示仍可运行 |

后台管理开关由你核对后保存，应用不能读取这些原厂开关。开机首次解锁后尝试恢复；强行停止、限制后台和系统电源保护可能阻止恢复。前台服务仍向系统提供运行通知；关闭通知权限时通知抽屉不显示，系统“活动应用”仍有运行标识。详见 [设置说明](docs/SETUP.md) 和 [权限与隐私](docs/PRIVACY.md)。

背屏朝下、被双击暂时熄灭或受睡眠/省电/温度策略限制时，即使画面已提交也可能不点亮；请区分系统背屏熄灭与应用停止。

抬起亮屏、人脸识别或相机使用时，固件的高优先级场景可能短暂显示 Amoo/系统图案，然后恢复电量。应用不关闭相机联动或改变系统优先级。

## 兼容性与限制

目前仅验证 **STEPX PZ261A、Android 16 / API 36、Step AOS 1.0.0.2 固件**。最低安装版本为 Android 14，不代表其他设备或 Android 版本已经兼容。背屏接口、旋转和旁路通知依赖原厂固件，OTA 后需重新确认。

AC 旁路从等待到生效的硬件切换、低电量完整充电过程、来电与相机冲突、高温及长期运行尚未完成实机验证。内部版曾通过解锁后开机恢复；公开包名未重新做重启测试。1.1.0 的真实消息及音乐应用适配尚未完整验收；另发现一次重新启用后低频恢复任务未建立，正在排查，不能保证进程被系统清理后的自动恢复。详见 [验证范围](docs/TESTING.md)。

## 开发

原生 Java，无第三方运行时依赖。需要 Python 3.9+、JDK 17、Android SDK platform 36 / build-tools 36.0.0。

```sh
python3 tools/test.py
python3 tools/build.py
```

默认生成独立开发签名的 `dist/backscreen-toolbox-1.1.0-dev.apk`，不能覆盖正式签名的安装包。正式构建必须显式指定已有私钥，工具不会自动生成“正式签名”。详见 [构建说明](docs/BUILD.md)。
