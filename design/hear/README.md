# 听见 · 竖屏绘图候选

此目录保留“听见”的六种离线绘图探索。先前的峰值 / RMS 双层轮廓未通过视觉认可；用户随后选定 D 频谱山形，并在 2026-10-19 确认安装后的竖屏实物效果可发布。这些候选文件不在 APK 的构建输入内，离线导出不会开启麦克风。

- A 单线示波：从 48 kHz PCM 中选取约 6 ms 的时域窗口，做 15 点时间片归约，绘制一条清晰连续线。
- B 实心波形：使用 A 相同的数据，填充至零位，用完整块面增强主体。
- C 竖向声带：21 个 25 ms 时间片沿竖向排列，峰值构成边缘，RMS 表达内部亮度。当前声段在底部，过去的声段向上移出；全屏显示约 525 ms 的节奏。

A/B 的时域窗口使用上升过零点减少任意相位跳变；有限像素只表达经过归约的形状，不能把它当作示波器测量。三者均使用固定显示增益和软限幅；不逐帧自动放大，不把输入画成预设正弦。C 不表达频谱或声源方向。

运行装有 Pillow 的 Python：`python3 tools/hear_style_preview.py`。工具使用相同的合成声音驱动三种候选，生成原生 17×23 点阵的对比循环、独立循环和关键帧。会检查静音、声强变化、时域形状变化、反相声道、直流、边界及 PCM 复用；不会读取真实声音。A/B/C 未集成到生产应用。

参考 [MDN 时域波形绘制](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Visualizations_with_Web_Audio_API#creating_a_waveformoscilloscope) 的采样到连续路径表达；候选为独立绘制，不复制其代码或素材。

## 第二组：频谱与声音驱动动效

用户继续希望看到其他选择，因此本组换用不同构图。用 `python3 tools/hear_style_preview.py --set motion` 导出，不覆盖第一组图，也不修改手机。

- D 频谱山形：将 80 Hz–12 kHz 的 15 个对数频段按低到高排列。高度来自真实输入的频段能量，固定显示增益，较暗块面与明亮顶部构成一个主体。
- E 声纹光环：使用 D 相同的 15 段频谱，沿圆周排列，以径向起伏表达能量。它不表示声源方位，也不是多个麦克风的空间定位。
- F 声波涟漪：以短时 RMS 驱动圆环的强度、范围和触发频率；持续声音可维持圆环向外展开。展开与淡出是视觉动效，不表示实际声波传播速度、时域波形或频谱。

频谱采用 48 kHz 输入、最多 1,200 样本（25 ms）Hann 窗、2,048 点零填充 FFT，按窗能量校正后积分频段功率。零填充不意味着提高真实频率分辨率。选择 AC 能量最强的声道，移除直流，防止反相抵消。显示端做短时稳定处理，未逐帧自动拉满；原始 PCM 不保留。先用已知低频 / 高频、正弦 RMS、幅度倍数、直流与反相声道核对计算，再检查留白、静音和清空。

第二组离线预览使用同一组合成低频、高频和短促噪声，均非实拍。频域可视化的概念参考 [MDN 频域数据说明](https://developer.mozilla.org/en-US/docs/Web/API/AnalyserNode/getFloatFrequencyData)，实现与图案为本项目独立编写。

## 选择与集成

用户已选定 D 频谱山形。正式实现为 `app/src/com/stepxadvance/backscreentoolbox/SoundSpectrum.java`，接入“听见”真实采集；此目录 D 候选共用正式频段计算与绘图函数，避免预览和实际画面产生两套样式。其他候选仍为离线探索。安装、真实采集及用户竖屏视觉确认的范围见 [验证记录](../../docs/TESTING.md#已选定-d频谱山形集成)。
